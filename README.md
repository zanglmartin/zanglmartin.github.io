## What I work on

- **Architecture modernization:** I replace risky parts of legacy mobile systems in stages, with tests around the behavior that must remain stable.
- **Offline-first reliability:** I keep pending work, ordering, and retry policy visible to the app so synchronization can be inspected and recovered.
- **SDK and platform consistency:** I trace SDK behavior across Android, iOS, Flutter, and React Native when a fix or release crosses platform boundaries.
